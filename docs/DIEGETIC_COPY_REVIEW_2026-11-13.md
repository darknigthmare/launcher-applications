# Revue des textes du catalogue — 13 novembre 2026

Les 112 fiches de jeux du catalogue récent ont été relues. La correction porte sur 99 fiches : 97 descriptions, 61 accroches, 27 listes de tags et deux genres. Les liens, politiques d’accès, noms, chemins média, versions de source et preuves de provenance sont conservés. Les 46 fiches intégrées directement dans `index.html` ont fait l’objet d’une lecture séparée : 33 jeux, six simulations fictives et sept outils réels ; 19 propositions ont été transmises au responsable du fichier.

Les descriptions présentent désormais le lieu, le rôle du joueur, ses actions et les enjeux. Les versions, moteurs, méthodes d’installation, réserves de fidélité et conditions de validation restent dans les métadonnées ou les dossiers de preuve. Le fichier [de revue détaillée](DIEGETIC_COPY_REVIEW_2026-11-13.json) conserve les anciens textes et les modifications ; ces anciens textes ne constituent pas un état actuel du jeu.

Une description sourcée ne remplace pas une validation de tous les parcours d’un jeu ; aucune nouvelle certification de complétude ou de fidélité canonique n’est créée par cette passe rédactionnelle.
