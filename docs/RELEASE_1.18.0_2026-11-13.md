# Launcher 1.18 — hébergements des cinq jeux

Les cinq projets Vercel ont été créés dans `darknigthmares-projects` et liés aux bons dépôts GitHub. DIVA PULSE, Dernière Ligne et Massilia Cyberpunk disposent de productions READY, de fichiers comparés aux sources et de parcours réels sur leurs domaines publics. Le [rapport de déploiement](WEB_GAME_DEPLOYMENTS_2026-11-13.json) distingue ces jeux des projets encore en attente ; les preuves locales de captures ne sont pas converties en preuves de production.

Les fiches de ces trois productions ouvrent directement leur jeu avec **Jouer**. Les anciennes destinations GitHub et politiques locales stockées dans le navigateur sont migrées. Les favoris, noms personnalisés, 27 illustrations acceptées, 118 textes diégétiques et médias natifs restent conservés. Massilia est désormais décrit en version source web 0.78, tandis que ses captures historiques restent identifiées en 0.76.

Fallout Mistral prépare une livraison statique complète de ses données cartographiques avec transport gzip et audits de construction datés. Parallaxe conserve son domaine de jeu et dispose d’un adaptateur Vercel avec salons durables dans un schéma Supabase privé : secret propre au service, données non accessibles aux clients anonymes, expirations de douze heures et contrôle atomique de révision. Les tests du stockage réel et les tests locaux sont consignés séparément des contrôles publics.

La limite gratuite Vercel de **100 déploiements par jour** a été atteinte pendant ce travail. Le refus `api-deployments-free-per-day` et le contrôle GitHub « Deployment rate limited — retry in 24 hours » empêchent de publier les nouvelles versions restantes. Le forfait gratuit est conservé. Les destinations détenues de Fallout et Parallaxe sont enregistrées, avec **Publication en attente** désactivé dans les fiches et la vitrine. Elles ne sont pas annoncées jouables sur la seule existence d’un domaine ou d’une construction ancienne.

Cette version du launcher reste à publier : le domaine public conserve la version 1.17 tant qu’aucun déploiement exact de cette révision n’est READY. Après rétablissement du quota, publier les SHA source finaux indiqués dans le rapport, vérifier leurs actifs et leur gameplay public (dont deux clients pour Parallaxe), remplacer les entrées `pending` par des preuves `deployments`, puis retirer `deployment-pending` seulement pour les jeux effectivement vérifiés. Le déploiement final du launcher doit pointer sur le commit testé et poussé de la PR.

Le cache passe à **shell v34 / médias v5**. `npm test` contrôle les preuves de production ou de blocage, les médias et les versions historiques. `npm run test:browser` contrôle notamment les boutons actifs et désactivés, les migrations des anciens catalogues, les galeries, les personnalisations, les favoris et le mobile. Le diagnostic des liens conserve le véritable état HTTP des publications en attente sans le présenter comme une destination jouable.

Validation locale : **12 398 contrôles statiques, 10 cas du classificateur et 31 vérifications Chromium réussis**, dont les trois liens Jouer, les deux publications désactivées et la migration des cinq anciennes destinations. [Rapport navigateur](verification/browser-1.18-2026-11-13.json). Le [diagnostic des 158 destinations](link-proof/web-launch-links-1.18-2026-11-13.json) observe 155 pages accessibles, un accès protégé et deux publications en attente ; leurs vrais statuts HTTP sont conservés, dont le 404 de Fallout et le 200 de la page Parallaxe, insuffisant pour valider son API.

Les changements d’hébergement sont committés dans les PR source : [DIVA #4](https://github.com/darknigthmare/Diva-Pulse/pull/4), [Dernière Ligne #4](https://github.com/darknigthmare/The-Horde-The-Last-Stand/pull/4), [Massilia #8](https://github.com/darknigthmare/massilia-cyberpunk/pull/8), [Fallout #21](https://github.com/darknigthmare/fallout-Marseille/pull/21) et [Parallaxe #6](https://github.com/darknigthmare/Parallaxe_Protocole9/pull/6). Les commits des configurations ultérieures ne sont pas confondus avec les sources exactes des trois productions déjà publiées.
