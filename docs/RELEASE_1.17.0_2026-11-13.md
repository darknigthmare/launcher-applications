# Launcher 1.17 — illustrations, descriptions et accès web

Le catalogue conserve 158 fiches, 145 jeux, les 790 chemins de captures et les 112 illustrations archivées. Cette vague ajoute 27 illustrations promotionnelles générées depuis les captures natives, sans remplacer les fichiers qui servent de preuve de gameplay. Le manifeste et les revues conservent les SHA, prompts, références, différences et verdicts ; l’interface n’affiche que les verdicts acceptés. L’acceptation porte sur la cohérence avec les références, sans certification exacte pixel par pixel ni canonique globale.

Les 99 fiches récentes et 19 fiches historiques corrigées emploient des descriptions diégétiques et des actions attestées. Les avertissements et informations de QA restent dans le mode édition et les documents. Deux genres sont corrigés selon leurs sources. Les images personnelles ont priorité sur l’illustration officielle ; modifier le nom d’une fiche conserve les médias natifs et l’illustration hydratée.

Les liens de jeu web utilisent Jouer. Les cinq anciennes distributions GitHub n’ont aucune adresse Vercel confirmée dans les projets, alias et variantes de nom examinés : elles disposent d’un bouton désactivé Adresse web à confirmer et d’un filtre dédié. Les sources et preuves historiques restent intactes. Aucune fausse URL n’est substituée. Les adresses exactes demeurent une information manquante demandée à l’utilisateur.

Le cache passe à shell33/médias4 et inclut le manifeste d’illustrations. L’attribution OpenStreetMap traverse les revues, le manifeste puis la fiche et la vitrine. Les tests couvrent l’intégrité des fichiers/références, l’hydratation des illustrations acceptées, le rejet des attributions stockées et les parcours navigateur.

Le projet Vercel de publication reste launcher-applications dans darknigthmares-projects. La PR de cette livraison indique le SHA exact testé, le statut de CI, le déploiement et la vérification du domaine public.
